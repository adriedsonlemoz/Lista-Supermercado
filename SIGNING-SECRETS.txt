MEU SUPERMERCADO — ASSINATURA PERMANENTE

O workflow aceita qualquer UM destes conjuntos de nomes de Secrets.

Conjunto recomendado:
ANDROID_KEYSTORE_BASE64
ANDROID_KEYSTORE_PASSWORD
ANDROID_KEY_ALIAS
ANDROID_KEY_PASSWORD

Alternativas reconhecidas:
LISTA_MERCADO_KEYSTORE_BASE64 / LISTA_MERCADO_KEYSTORE_PASSWORD / LISTA_MERCADO_KEY_ALIAS / LISTA_MERCADO_KEY_PASSWORD
KEYSTORE_BASE64 / KEYSTORE_PASSWORD / KEY_ALIAS / KEY_PASSWORD
SIGNING_KEY / SIGNING_STORE_PASSWORD / SIGNING_KEY_ALIAS / SIGNING_KEY_PASSWORD

IMPORTANTE:
- ANDROID_KEYSTORE_BASE64 (ou equivalente) deve conter o arquivo .jks/.keystore inteiro codificado em Base64.
- Não gere uma chave nova a cada build.
- Use sempre a mesma chave para poder instalar atualizações sobre a versão já instalada.
- A chave privada não deve ser incluída no ZIP público do código-fonte.
